# Photoshop JSX Generator

## Описание

Небольшой Python-скрипт, который генерирует `.jsx`-сценарий для Adobe Photoshop. В текущем виде проект собирает автоматизированный скрипт цветокоррекции с набором корректирующих слоёв.

## Назначение

- программно формировать JSX-файл для Photoshop;
- автоматизировать повторяющиеся шаги ретуши и цветокоррекции;
- хранить шаблон действий в виде обычного Python-кода.

## Стек

- Python
- Adobe Photoshop JSX

## Запуск

```bash
python Generate_jsx_ps.py
```

После запуска рядом будет создан файл `her_style_color_correction.jsx`, который можно открыть или выполнить в Photoshop.

## Статус

WIP. Проект компактный, но полезный как заготовка для автоматизации графических пайплайнов.
